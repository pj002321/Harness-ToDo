## 핵심 원칙 (OpenAI 하네스 엔지니어링 기준)

- **저장소 = 지식의 기록 시스템.** 에이전트 컨텍스트에 없는 결정은 존재하지 않는 것과 같다.
  Slack/문서 툴/사람 머릿속의 결정은 전부 `docs/`로 옮겨야 한다.
- **AGENTS.md는 매뉴얼이 아니라 지도.** 짧게 유지하고, 깊은 내용은 링크로 연결한다.
- **좋은 코드를 "부탁"하지 않고 "강제"한다.** 의존성 방향, PR 형식, 품질 기준을 지시가 아니라
  구조 테스트/템플릿/CI 게이트로 강제한다. <!-- TODO: 이 프로젝트의 구조 테스트 위치 명시 -->
- **관측성이 검증의 근거.** 사람이 눈으로 리뷰하는 대신 메트릭/로그로 판정한다.
- **엔트로피는 별도 관리 대상.** `maintenance/`에 자동 정리 스크립트를 둔다.
